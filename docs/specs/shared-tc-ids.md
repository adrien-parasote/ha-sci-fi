# TC-IDs partagés entre deux specs

Un identifiant listé ici est déclaré par une feature et cité, volontairement, par
une autre spec qui décrit la même surface : la citation renvoie au même cas, pas
à un cas homonyme. Une puce par identifiant — jamais une ligne de tableau, que le
garde O1 (`tests/specs/ids-cas-uniques.test.ts`) lirait comme une déclaration de
plus.
